My Project Widget

Цель проекта
Данный проект предназначен для обработки данных с использованием функций фильтрации и сортировки.

Реализована функция, которая принимает:
    на вход транзакцию и возвращает сумму транзакции 
    на вход путь до JSON-файла
Реализованы функции для работы с файлами данных:
    читает транзакции из CSV файла по указанному пути
    читает транзакции из EXEL файла по указанному пути.
Создан шаблон файла .env

Написаны тесты для новых функций, используйте pytest, Mock и patch
Созданы конфигурации логирования - запуск через: python main.py
